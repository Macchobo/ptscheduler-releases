# PT 스케줄러 — Mac 앱

PT 트레이너용 스케줄 비서 앱의 **Mac 설치 파일**과 **자동 업데이트** 파일만 올리는 곳이에요. (앱 코드는 여기 없어요)

## 설치
1. 오른쪽 **Releases**에서 가장 최신 버전을 열어요.
2. 내 Mac에 맞는 DMG를 받아요.
   - Apple 칩(M1·M2·M3…): `PT-Scheduler-버전-arm64.dmg`
   - Intel 칩: `PT-Scheduler-버전.dmg`
   - 모르면:  → 이 Mac에 관하여 → "칩"이 Apple이면 arm64
3. DMG를 열고 **PT 스케줄러**를 Applications(응용 프로그램) 폴더로 끌어 넣어요.

## 업데이트
한 번 설치하면 그다음부터는 **자동**이에요. 앱을 켤 때 새 버전을 받아 두고, 다음에 켤 때 바뀌어요.
화면 변경은 대부분 앱을 껐다 켜기만 하면 바로 반영돼요.
