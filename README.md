# PT 스케줄러 — Mac · 윈도우 앱

PT 트레이너용 스케줄 비서 앱의 **설치 파일**과 **자동 업데이트** 파일만 올리는 곳이에요. (앱 코드는 여기 없어요)

## 설치
오른쪽 **Releases**에서 가장 최신 버전을 열고, 내 컴퓨터에 맞는 파일을 받아요.

### Mac
- `PT-Scheduler-버전-arm64.dmg` (Apple 칩 M1·M2·M3… Mac 전용 — 인텔 Mac은 지원하지 않아요)
- DMG를 열고 **PT 스케줄러**를 Applications(응용 프로그램) 폴더로 끌어 넣어요.

### 윈도우
- `PT-Scheduler-Setup-버전.exe`를 받아 실행해요.
- 처음 설치할 때 **"Windows의 PC 보호"** 파란 창이 뜨면 → **[추가 정보]** → **[실행]** 을 눌러요. (코드 서명 인증서가 아직 없어서 뜨는 안내예요)

## 업데이트
한 번 설치하면 그다음부터는 **자동**이에요. 앱을 켤 때 새 버전을 받아 두고, 다음에 켤 때 바뀌어요.
화면 변경은 대부분 앱을 껐다 켜기만 하면 바로 반영돼요.
